# 로컬 메시지 처리 검사

웹은 개인용 브라우저 저장만 사용합니다. 서버 업로드 스크립트와 앱의 로그인·자동 연동 관리 UI는 제거했습니다. 실제 카톡 공지는 PM 화면의 **카톡 공지 반영**에 붙여넣습니다.

- `kakao-events.js`: 시각이 확인된 관측 메시지를 순수 함수로 계산합니다. 네트워크 요청이나 외부 저장은 없습니다.
- `plan.cjs`: 일정 공지와 관측 메시지를 시간순으로 계산하는 검사 도우미입니다. 브라우저 UI/저장소를 모의한 환경에서 실행하며 외부 저장을 하지 않습니다.
- `headless-app.cjs`: 회귀 검사용 DOM·브라우저 저장소 모의 환경입니다.

```sh
node --test tests/pm-regression.cjs tests/kakao-automation.cjs
```

원문을 실행하거나 지시로 취급하지 않습니다. 날짜·시각이 불명확하거나 미완료·취소·예정인 메시지를 실제 완료로 추정하지 않습니다. 별도 작업 일정은 약품 PM 회차의 기준으로 사용하지 않습니다.
