# 동도금 PM

실제 웹 진입 파일은 `index.html`입니다. 개인용 브라우저 저장을 사용하며 기존 기기 기록과 영구 저장 키를 보존합니다.

## 화면과 사용 흐름

- **PM 관리**: 상단 조회·알림 → 날짜 선택과 공지 복사 → 카톡 공지 붙여넣기·미리보기 → 화학동 카드 순서입니다. 미리보기와 붙여넣기는 기본으로 펼쳐두며, 붙여넣으면 별도 확인 없이 즉시 반영합니다. 직접 수정한 경우에만 수정 내용 반영 버튼을 표시합니다. 메시지 시각이 필요하면 입력을 유지하고 시각을 선택할 때 다시 반영합니다. 복사는 기존 원문의 줄바꿈·표제·마무리를 유지하며, 복사 제한 시 선택 가능한 원문을 펼칩니다.
- 첫 화면 날짜는 **월·일만** 표시하며 오늘·내일과 한 줄로 정렬합니다. 날짜 선택과 월말·연말 계산에는 실제 연도를 유지합니다.
- 화면의 “동도금 PM” 제목은 제거하고 **🗓️ 주간 매트릭스·🧪 액퍼내기** 버튼만 PM 관리 상단에 표시합니다. 특이사항 탭에서는 헤더를 숨깁니다. 두 조회 팝업은 닫기 버튼 없이 바깥 화면 터치·상단 아래로 쓸어내리기·Escape로 닫힙니다. 표는 스크롤 맨 위에서 아래로 당길 때 닫고, 가로 스크롤이나 아래쪽 내용 조회는 유지합니다. 팝업을 닫으면 원래 화면 위치로 돌아옵니다. 액퍼내기 표는 조회 전용입니다.
- 카톡 공지 미리보기는 이전처럼 시스템 글꼴·16px·보통 굵기로 표시합니다. 라인명만 굵게 강조하거나 제목·마무리의 글자 크기와 색을 다르게 표시하지 않습니다.
- 화7·8·9·13·14는 흰색 카드에 라인·작업명, 상태 배지, 주요 시각, 보조 시각 순으로 표시합니다. 상태 색상은 배지와 얇은 막대에만 사용하며, 진행 중 액이송·PM 목표 시각은 나란히 표시합니다. **PM 시작/완료·시간정정**은 카드 하단에 분리하고 터치 영역을 44px 이상으로 유지합니다. 완료는 확인 후 현재 시각부터 차기 72시간을 계산합니다. 특이사항의 기록 정정도 유지합니다.
- 카드의 얇은 막대는 다음 PM까지의 경과 비율 또는 진행 중 14시간 목표 경과를 표시합니다. 12시간 액이송 기준선을 표시하며 막대가 끝나도 자동 완료하지 않습니다. 시간·작업·실제 완료 근거와 기존 경고 기준을 유지합니다.
- 일반 특이사항은 문장 또는 날짜·라인·내용으로 확인 후 저장합니다. **🔧 공사·점검·🧪 액퍼내기·⚡ 요일 변경·🛠️ 기타 교체** 빠른 입력은 수정할 초안만 열며 자동 저장하지 않습니다. 액퍼내기 초안은 기존 확정일이 있으면 그 날짜를 제시합니다.
- 시간정정의 수동 분 선택은 00/30분이며 기존 저장값과 카톡 메시지의 정밀도는 유지합니다. 중복 요약, 진척 탭, 디13·14 전용 입력란, 개인용 자동 저장 문구는 표시하지 않습니다. 저장 실패 시에만 경고합니다.
- 모바일에서는 두 탭을 하단에 고정합니다. iOS safe area와 입력 글꼴 16px를 유지합니다.

액퍼내기는 **달력상 한 달 전부터 PM 관리 상단에 알림**을 표시합니다. 이전 달에 같은 일자가 없으면 그 달 마지막 날부터 표시합니다. 예를 들어 3월 31일 예정은 2월 마지막 날부터 알립니다. 예정일 당일과 초과 상태도 유지합니다. 닫으면 현재 날짜의 같은 일정은 숨기고, 다음 날 또는 확정일 변경 시 다시 표시합니다. 웹 화면 안의 알림이며 별도 메일·푸시를 발송하지 않습니다.

## 특이사항으로 일정 변경

문장을 입력하고 **문장에서 일정 가져오기** → 날짜·라인·내용 확인 → **저장**합니다. 날짜·라인 직접 입력도 같은 검사를 사용합니다.

- `디12 10월 28일 옥사멧 점검`: 해당 날짜 정기 PM에 `(옥사멧 점검)`을 덧붙입니다. 정기 PM이 없는 날은 별도 작업만 표시하며 약품 PM을 만들지 않습니다.
- `전20 10월 30일 액퍼내기 확정`: 액퍼내기 예정일과 날짜별 공지·주간 매트릭스에 반영합니다. 예정 확정은 최근 완료일을 변경하지 않습니다.
- `전20 10월 30일 액퍼내기 완료`: 실제 완료 날짜에만 저장할 수 있으며, 그 완료일로부터 120일 후를 계산합니다. 미래 완료는 저장하지 않습니다.
- `전12 PM 목요일로 변경`: 입력일을 적용 시작일로 사용하고 기존 격주 주기를 유지합니다.
- `전12 11월 2일부터 PM 매주 화요일로 변경`: 지정한 날짜부터 매주 화요일로 변경합니다. 매주/격주를 생략하면 기존 주기를 유지합니다. 공지·라인 목록·매트릭스에 같은 규칙을 적용합니다.

액퍼내기 확정일은 새 일정으로 교체할 수 있습니다. 저장 목록에서 수정·삭제할 수 있고 변경은 새로고침 후에도 유지됩니다. PM 요일 변경은 일반 특이사항처럼 괄호에 넣지 않고 실제 반복 일정을 변경합니다.

일반 특이사항에는 약품 건욕·기본 PM을 기록하지 않습니다. 약품 배관 공사·건욕 탱크 보수·산세 펌프 교체 같은 별도 설비 작업은 허용합니다. 태그는 유산동 필터 교체·옥사멧 점검·인써트 교체·설비공사·설비점검을 제공합니다.

## 확정된 기본 변경

- 2026-10-28부터 **전12: 금요일 → 목요일**, 기존 격주 위상 유지. 10월 29일에 적용하며 10월 30일에는 중복 표시하지 않습니다.
- **전20: 2026-10-30 액퍼내기 확정**. 실제 완료로 만들지 않으며, 특이사항에 새 확정일을 저장하면 그 날짜를 우선합니다.

## 카톡 공지와 디13·14

디13·14 전용 수동 PM 기록을 제거했습니다. 날짜가 있는 PM 공지를 첫 화면에 붙여넣으면 작업명과 날짜를 기준으로 적용합니다.

예: `동도금 10월 28일 PM일정\n디13 30일 망간 건욕\n디14 기본PM`

- 해당 디스미어 라인의 최신 붙여넣기가 이전에 가져온 날짜·내용을 교체합니다. 날짜가 꼬였으면 최신 공지에서 그 라인을 포함하여 다시 붙여넣습니다. 기존 다른 라인 기록과 별도 특이사항은 유지합니다.
- 날짜가 없는 디13·14 공지는 즉시 저장하지 않고 메시지 날짜·시각 확인을 요청합니다.
- 공지 날짜는 기준 일정입니다. 디13·14 공지를 붙여넣는 것만으로 화학동 시작·완료를 만들지 않습니다.
- 공지로 정한 기준일 이후 실제 화학동 완료 2회마다 디스미어 1회를 안내합니다. 기준을 새 공지로 바꾸면 그 날짜 이후 실제 회차를 다시 계산합니다.
- 오래된 수동 기록은 보관하지만 새 카톡 공지가 있으면 해당 라인은 새 공지를 우선합니다.
- 날짜 없는 화학동 진행/완료 시간이 현재보다 미래면 전날로 해석합니다. 명시적 미래 완료·취소·미완료·단순 측정값은 실제 완료로 만들지 않습니다.
- 백라이트에서 PM 진행 근거를 보관하고 이후 날짜·시각이 있는 양산/액수위 신호로 완료 후 72시간을 계산합니다. 중복 메시지는 회차를 중복 집계하지 않습니다.

## 유지하는 공정 기준

- 전기동 공지는 **7시패스 고정**. 붙여넣은 다른 패스 시간과 과거 저장값은 무시합니다.
- 전9·12·14·20·21은 산탈지.산세.박리, 나머지는 산세.박리를 기본으로 사용합니다.
- 에칭은 일요일 포함 에1.2 → 에3.4 → 에6 순환, 2026-09-25 = 에3.4 기준입니다.
- 화학동 실제 완료 후 72시간, 7시간 이내 임박, 진행 12시간 액이송·14시간 목표 초과 지연, 화8 완료 후 48시간 초과 빌드업 금지를 유지합니다.
- 일일 공지의 화학동 포함 범위는 당일 08:30 이상부터 익일 08:30 미만입니다.
- 기존 전기동·펄스 타이머 저장 기록은 보존하며 진척 UI는 다시 표시하지 않습니다.

## 저장과 복구

`pm_local_state_master`에 전체 상태를 한 번에 저장하고 기존 마스터 키를 호환 사본으로 유지합니다. 모든 버전 키를 역순 탐색하여 정상 기록을 복구하며 손상된 일부 필드 때문에 정상 필드를 지우지 않습니다. 실제 기록 없는 화학동은 임의 시각 대신 기록 확인 필요 상태로 표시하며 5개 라인은 항상 유지합니다.

로그인·서버 저장·연결·데이터 관리 메뉴·업로드 CLI를 사용하지 않습니다. CSP `connect-src 'none'`으로 외부 데이터 연결을 막습니다. 기기·브라우저·사이트 주소가 다르면 기록을 공유하지 않으며, 브라우저 사이트 데이터를 지우면 기록도 삭제됩니다. 대화 원문은 저장하지 않습니다.
