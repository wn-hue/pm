# 동도금 PM

실제 웹 진입 파일은 `index.html`입니다. 개인용 브라우저 저장을 사용하며 기존 기기 기록과 영구 저장 키를 보존합니다.

앱 아이콘은 블루 배경과 흰색 캘린더·체크 심볼을 사용합니다. 원본은 `app-icon.svg`이며 아이폰용 `apple-touch-icon.png`(180px), 모바일 설치용 192/512px PNG, 브라우저용 PNG/ICO를 같은 원본에서 생성합니다. HTML의 명시적 아이콘 링크와 `site.webmanifest`를 통해 연결하며 홈 화면 이름은 **PM 관리**입니다.

## 화면과 사용 흐름

- 화면은 시스템 글꼴과 기기의 밝은 화면·다크 모드 설정을 사용합니다. 휴대폰에서는 한 열로, 넓은 PC에서는 공지와 화학동 현황을 나란히 보여줍니다. 외부 폰트·이미지 요청 없이 동작 줄이기·투명도 줄이기·대비 높이기 설정을 따릅니다.
- **PM 관리**: 상단 날짜·조회 → 액퍼내기 알림 → 오늘/내일 전환 → 카톡 공지 붙여넣기·미리보기 → 화학동 목록 순서입니다. 화학동 바로가기에 주의·진행 건수를 표시하고 지연 → 임박 → 화8 빌드업 금지 → 진행 순서로 첫 해당 라인에 이동합니다. 목록은 6개 라인의 고정 순서를 유지하며, 목록 위의 **공지 보기**로 미리보기에 돌아옵니다. 미리보기와 붙여넣기는 기본으로 펼쳐두며, 미리보기를 직접 접으면 그 기기에서 다음에도 접힌 상태로 열어 휴대폰 첫 화면에 화학동 목록이 바로 보입니다. 공지를 붙여넣으면 확인용으로 미리보기를 다시 펼치지만 접힘 설정은 유지합니다. 붙여넣으면 별도 확인 없이 즉시 반영한 뒤 입력창을 비우고 키보드를 닫습니다. `paste`와 `insertFromPaste` 입력을 모두 처리하며 두 이벤트가 와도 한 번만 적용합니다. 직접 입력하는 중에는 자동 처리하지 않고 반영 버튼을 표시합니다. 날짜·시각 보완 입력은 제거했습니다. 필요한 날짜·시각이 없는 항목은 제외하며 기존 기록을 유지합니다. 반영된 라인명을 결과 한 줄로 표시하고, 같은 자리의 **되돌리기**로 방금 가져온 기록을 취소할 수 있습니다. 복사는 기존 원문의 줄바꿈·표제·마무리를 유지하며, 복사 제한 시 선택 가능한 원문을 펼칩니다.
- 첫 화면 날짜는 **월·일만** 크게 표시하고 요일과 오늘/내일을 함께 안내합니다. 오늘·내일 전환은 별도 한 줄로 정렬합니다. 날짜 선택과 월말·연말 계산에는 실제 연도를 유지합니다.
- PM 관리 상단에 **🗓️ 주간 매트릭스·🧪 액퍼내기**를 표시합니다. 특이사항 탭에서는 헤더를 숨깁니다. 주간 매트릭스는 선택한 날짜를 처음에 보여주고, 스크롤 중에도 공정명과 요일을 표시합니다. 휴대폰에서는 액퍼내기 일정을 라인별 카드로 확인합니다. 팝업은 바깥 화면 터치, 상단을 아래로 밀기, Escape로 닫고 원래 화면 위치로 돌아옵니다.
- 카톡 공지 미리보기는 이전처럼 시스템 글꼴·16px·보통 굵기로 표시합니다. 라인명만 굵게 강조하거나 제목·마무리의 글자 크기와 색을 다르게 표시하지 않습니다.
- 화7·8·9·13·14와 P1B화1은 한 개의 간결한 목록에 고정 순서로 표시합니다. 기본 화면은 **라인·상태·핵심 시각·시작/완료 버튼**으로 구성합니다. 대기 중에는 다음 PM, 진행 12시간 전에는 액이송, 그 이후에는 14시간 PM 목표를 표시하며 자동 완료하지 않습니다. 시각은 오늘·내일·어제 또는 월일과 24시간 시각으로 간결하게 표시합니다. 핵심 시각 옆에는 `11시간 후`·`2일 5시간 후`·`3일 지남`처럼 남은/지난 시간을 함께 표시하고, 임박·지연이면 주황·빨강으로 강조합니다. 3시간 이상은 시간 단위로 내림하여 남은 시간을 부풀리지 않습니다.
- 라인을 펼치면 실제 시작·직전 완료·경과 시간(`3시간 30분` 형식)·12시간 액이송·14시간 목표와 **시간정정**을 확인할 수 있습니다. 분 단위 갱신 중에도 펼침 상태를 유지하고 매초 목록을 다시 만들지 않습니다. 큰 개별 카드·경과 막대·반복 기본PM 표기는 제거하고 실제 작업명과 화8 빌드업 금지 경고는 기본 화면에 유지합니다. 시작/완료 터치 영역은 44px 이상이며 한 번 누르면 현재 시각으로 반영합니다. 완료 시 차기 72시간을 계산하고, 해당 행의 **되돌리기**로 원래 상태·시각과 화13·14 완료 회차까지 함께 복원합니다.
- **특이사항** 페이지는 저장된 일정과 접힌 과거 기록을 먼저 표시합니다. 비어 있으면 왼쪽 정렬 안내 한 줄만 표시하며 새 기록은 하단 버튼에서 시작합니다. 입력 시트에서 문장 또는 날짜·라인·내용으로 확인 후 저장합니다. 확인 단계에서는 문장·빠른 입력을 접어 중복 입력을 줄입니다. 바깥 터치·아래로 쓸어내리기·Escape로 닫아도 작성 중 초안을 유지하고, 저장하면 시트를 닫고 목록에 반영합니다. **공사·점검·액퍼내기·요일 변경·기타 교체** 빠른 입력은 수정할 초안만 열며 자동 저장하지 않습니다. 액퍼내기 초안은 기존 확정일이 있으면 그 날짜를 제시합니다.
- 화학동 행을 왼쪽으로 밀거나 상세의 **시간정정**을 누르면 수정 창이 열립니다. 일·시·분은 각 열을 위아래로 밀거나 숫자를 눌러 고릅니다. 분 선택은 00/30분이며, 기존 기록이 30분이면 30분으로 열리고 그 외는 00분으로 열립니다. **시간 저장**을 눌러 반영하기 전까지 기존 기록 시각을 유지합니다. 중복 요약, 진척 탭, 디13·14 전용 입력란, 개인용 자동 저장 문구는 표시하지 않습니다.
- 하단에는 두 탭과 페이지별 주 동작을 함께 고정합니다. PM 관리에서는 선택한 월일과 **공지 복사**, 특이사항에서는 **새 특이사항**을 표시합니다. 탭을 오가면 각각 보던 스크롤 위치로 돌아가며, 현재 탭을 다시 누르면 맨 위로 이동합니다. 키보드가 올라오면 하단 메뉴를 숨기고 입력 시트 높이를 보이는 영역에 맞춥니다. iOS safe area·입력 글꼴 16px·44px 이상 터치 영역을 유지합니다.

액퍼내기는 **달력상 한 달 전부터 PM 관리 상단에 알림**을 표시합니다. 이전 달에 같은 일자가 없으면 그 달 마지막 날부터 표시합니다. 예를 들어 3월 31일 예정은 2월 마지막 날부터 알립니다. 예정일 당일과 초과 상태도 유지합니다. 닫으면 현재 날짜의 같은 일정은 숨기고, 다음 날 또는 확정일 변경 시 다시 표시합니다. 웹 화면 안의 알림이며 별도 메일·푸시를 발송하지 않습니다.

상단 액퍼내기 알림은 초과 일정, 가까운 예정일 순으로 한 건과 나머지 건수만 간결하게 표시합니다. 접근성 설명에는 모든 알림을 유지하며, 누르면 전체 예정일 표가 바로 열립니다. 오른쪽 숨기기 버튼은 별도로 동작합니다. 특이사항은 문장 입력·날짜/라인 선택·네 가지 작업 바로가기로 구성하며, 저장할 내용이 있을 때만 문장 반영 버튼을 표시합니다.

## P1B (MSF)

- P1B 전기동 1라인은 2026년 11월 2일부터 매주 화요일 정기 PM에 포함하며 공지에는 `P1B전1 기본PM (7시패스)`로 표시합니다. 기존 MSF 전기동 액퍼내기 기록과 같은 라인으로 연결합니다.
- P1B 데버링·디스미어 1라인은 2026년 11월 26일부터 매주 목요일에 표시합니다. 복사용 공지에는 `P1B데1`, `P1B디1 기본PM`으로 표시하며, 주간 매트릭스와 특이사항에서 각각 같은 라인으로 연결합니다.
- P1B 화학동 1라인은 `P1B화1`로 기존 화학동과 구분합니다. 첫 예정은 2026년 11월 2일 18시이며 완료 기록을 만들지 않습니다. 실제 완료 후 72시간으로 다음 PM을 계산합니다.
- 공지의 `P1B화1`, `P1B 화학동 1라인`, `MSF 화1`, `P1B(MSF) 화학동 1라인`을 같은 화학동으로 인식하고 시작·완료·예정과 특이사항을 반영합니다. 전기동도 같은 접두어를 지원합니다.
- 이전 5개 화학동 백업도 검증 후 복원할 수 있으며 P1B 예정만 추가합니다. 기존 완료·시작·특이사항·MSF 액퍼내기 기록을 유지합니다.

## 특이사항으로 일정 변경

문장을 입력하고 **문장에서 일정 가져오기** → 날짜·라인·내용 확인 → **저장**합니다. 날짜·라인 직접 입력도 같은 검사를 사용합니다.

- `디12 10월 28일 옥사멧 점검`: 해당 날짜 정기 PM에 `(옥사멧 점검)`을 덧붙입니다. 정기 PM이 없는 날은 별도 작업만 표시하며 약품 PM을 만들지 않습니다.
- `전20 10월 30일 액퍼내기 확정`: 액퍼내기 예정일과 날짜별 공지·주간 매트릭스에 반영합니다. 예정 확정은 최근 완료일을 변경하지 않습니다.
- `전20 10월 30일 액퍼내기 완료`: 실제 완료 날짜에만 저장할 수 있으며, 그 완료일로부터 120일 후를 계산합니다. 미래 완료는 저장하지 않습니다.
- `전12 PM 목요일로 변경`: 입력일을 적용 시작일로 사용하고 기존 격주 주기를 유지합니다.
- `전12 11월 2일부터 PM 매주 화요일로 변경`: 지정한 날짜부터 매주 화요일로 변경합니다. 매주/격주를 생략하면 기존 주기를 유지합니다. 공지·라인 목록·매트릭스에 같은 규칙을 적용합니다.

액퍼내기 확정일은 새 일정으로 교체할 수 있습니다. 저장 목록에서 수정·삭제할 수 있고 변경은 새로고침 후에도 유지됩니다. PM 요일 변경은 일반 특이사항처럼 괄호에 넣지 않고 실제 반복 일정을 변경합니다.

일반 특이사항에는 약품 건욕·기본 PM을 기록하지 않습니다. 약품 배관 공사·건욕 탱크 보수·산세 펌프 교체 같은 별도 설비 작업은 허용합니다. 태그는 유산동 필터 교체·옥사멧 점검·인써트 교체·설비공사·설비점검을 제공합니다.

## 확정된 기본 변경

- 2026-10-28부터 **전12: 금요일 → 목요일**, 기존 격주 위상 유지. 10월 29일에 적용하며 10월 30일에는 중복 표시하지 않습니다.
- **전20: 2026-10-30 액퍼내기 확정**. 실제 완료로 만들지 않으며, 특이사항에 새 확정일을 저장하면 그 날짜를 우선합니다.

## 카톡 공지와 디13·14

`화7 19시 화학동 건욕`처럼 시각과 작업명을 붙여넣으면 PM 관리와 카톡 공지에 함께 반영합니다. 대기 중이면 예정 시각으로, 이미 진행 중이면 시작 시각 정정으로 처리합니다. `예정`으로 적은 공지는 예정으로 처리합니다. 화7의 기본 작업은 `촉매cs`이며, 공지에 작업명이 있으면 그 작업을 표시합니다.

`P1B디화1`과 `P1B디1화1`로 적은 화학동 진행 상황은 `P1B화1`에 반영합니다. 당일 동도금 PM 일정의 `PM 중` 줄에 날짜가 생략되어 있고 적힌 시각이 아직 오지 않았으면 전날 시작으로 해석합니다. `26일 0시`처럼 줄에 날짜를 적으면 그 날짜의 자정을 사용합니다. 화7에 같은 날의 완료 기록이 있으면, 공지의 시작 시각과 저장된 완료 시각을 확인한 뒤 **화7 진행 중으로 정정**을 눌러 적용할 수 있습니다.

진행 중인 화학동은 같은 PM 시작일의 공지를 다시 붙여넣으면 앞당겨진 시각도 반영합니다. 예를 들어 `화13 11시 20분 촉매 건욕 PM 진행중`은 시작 시각과 작업명을 갱신하고, 시각만 정정하면 작업명은 유지합니다. 여러 작업은 함께 표시하고, `추가: 세척수 순환` 또는 `+ 세척수 순환`을 같은 줄이나 바로 다음 줄에 적으면 기존 작업에 중복 없이 붙입니다. 공지에는 분과 작업명을 함께 표시하며, 공지 날짜와 실제 시작일이 다르면 시작일도 표시합니다.

디13·14 전용 수동 PM 기록을 제거했습니다. 날짜가 있는 PM 공지를 첫 화면에 붙여넣으면 작업명과 날짜를 기준으로 적용합니다.

예: `동도금 10월 28일 PM일정\n디13 30일 망간 건욕\n디14 기본PM`

- 해당 디스미어 라인의 최신 붙여넣기가 이전에 가져온 날짜·내용을 교체합니다. 날짜가 꼬였으면 최신 공지에서 그 라인을 포함하여 다시 붙여넣습니다. 기존 다른 라인 기록과 별도 특이사항은 유지합니다.
- 날짜가 없는 디13·14 공지는 저장하지 않습니다. 날짜가 포함된 공지를 다시 붙여넣으면 반영하며 수동 날짜·시각 보완 입력은 사용하지 않습니다.
- 공지 날짜는 기준 일정입니다. 디13·14 공지를 붙여넣는 것만으로 화학동 시작·완료를 만들지 않습니다.
- 공지로 정한 기준일 이후 실제 화학동 완료 2회마다 디스미어 1회를 안내합니다. 기준을 새 공지로 바꾸면 그 날짜 이후 실제 회차를 다시 계산합니다.
- 오래된 수동 기록은 보관하지만 새 카톡 공지가 있으면 해당 라인은 새 공지를 우선합니다.
- 날짜 없는 화학동 진행/완료 시간이 현재보다 미래면 전날로 해석합니다. 명시적 미래 완료·취소·미완료·단순 측정값은 실제 완료로 만들지 않습니다.
- 백라이트에서 PM 진행 근거를 보관하고 이후 날짜·시각이 있는 양산/액수위 신호로 완료 후 72시간을 계산합니다. 중복 메시지는 회차를 중복 집계하지 않습니다.

## 유지하는 공정 기준

- 전기동 공지는 **7시패스 고정**. 붙여넣은 다른 패스 시간과 과거 저장값은 무시합니다.
- 전9·12·14·20·21은 산탈지.산세.박리, 나머지는 산세.박리를 기본으로 사용합니다.
- 에칭은 일요일 포함 에1.2 → 에3.4 → 에6 순환, 2026-09-25 = 에3.4 기준입니다.
- 화학동 실제 완료 후 72시간, 7시간 이내 임박, 진행 12시간 액이송·14시간 목표 초과 지연, 화8 완료 후 48시간 초과 빌드업 금지를 유지합니다.
- 일일 공지의 화학동 포함 범위는 당일 08:30 이상부터 익일 08:30 미만입니다.
- 기존 전기동·펄스 타이머 저장 기록은 보존하며 진척 UI는 다시 표시하지 않습니다.

## 저장과 복구

시작·완료·카톡 반영의 **가장 최근 한 동작**은 다음 실제 데이터 변경 또는 앱 새로고침 전까지 되돌릴 수 있습니다. 되돌리기는 화면에만 보관하고 대화 원문은 저장하지 않습니다. 후속 특이사항·시간정정·백업 복원 또는 다른 창에서 바뀐 기록을 덮어쓰지 않으며, 시작·완료·붙여넣기 저장 실패 시 기존 상태를 유지합니다.

`pm_local_state_master`에 전체 상태를 한 번에 저장하고 기존 마스터 키를 호환 사본으로 유지합니다. 모든 버전 키를 역순 탐색하여 정상 기록을 복구하며 손상된 일부 필드 때문에 정상 필드를 지우지 않습니다. 실제 기록 없는 화학동은 임의 시각 대신 기록 확인 필요 상태로 표시하며 6개 라인은 항상 유지합니다.

기기를 연결하기 전에는 각 브라우저에 기록을 저장합니다. 연결된 기기는 같은 주소의 API를 사용하며, 클라우드에는 화학동·액퍼내기·특이사항·진행 기록 등 파싱된 PM 상태를 저장합니다. 대화 원문은 저장하지 않습니다. 오늘·내일과 PM 규칙은 기기 시간대에 관계없이 한국시간으로 계산합니다.

### 모든 기기에서 같은 기록 사용

1. 최근 기록이 있는 기기에서 개인 연결 링크를 엽니다. 홈 화면에 설치한 앱에서는 **특이사항 → 기기 연결 → 연결 파일 열기**에서 개인 연결 TXT 파일을 선택합니다.
2. 처음 한 번 **이 기기 기록으로 시작**을 눌러 기준 기록을 저장합니다. 서버가 비어 있을 때만 이 동작이 가능합니다.
3. 다른 휴대폰이나 PC에서 같은 개인 링크를 엽니다. 이미 연결된 기기의 **특이사항 → 기기 연결 → 다른 기기 연결**에서도 10분간 사용할 링크를 만들고 복사할 수 있습니다. 이후 평소 PM 주소로 접속하면 최신 기록을 가져오며 변경은 자동으로 저장됩니다.

두 기기에서 수정이 겹치면 먼저 저장된 버전을 보존하고 충돌을 표시합니다. **서버 기록 불러오기**를 선택할 때 이 기기의 기록을 따로 보관하므로 **이전 기기 기록 백업**으로 내려받을 수 있습니다. 연결이 끊긴 상태에서 저장한 변경은 기기에 보관하며 다시 연결되면 전송합니다.

운영 환경에는 `BLOB_READ_WRITE_TOKEN`, `PM_SYNC_CODE_SHA256`, `PM_SYNC_SESSION_SECRET`, `PM_SYNC_ORIGIN`이 필요합니다. 비공개 Vercel Blob에 전체 기록을 한 객체로 보관하고 버전이 맞을 때만 저장합니다. 개인 연결 링크의 인증 값은 열자마자 주소에서 제거하고, 이후 브라우저는 `HttpOnly` 세션 쿠키로 연결합니다. 개인 연결 파일은 비밀번호처럼 보관하세요. 동기화 환경이 설정되지 않은 배포본은 기기 내 저장으로 동작합니다.

### 앱 아이콘 변경·재설치 시 기록 옮기기

기존 앱을 먼저 삭제하지 마세요. **특이사항 → 앱 데이터 옮기기**를 펼치면 **백업 저장 / 백업 불러오기**를 같은 폭·높이의 목록으로 표시합니다. 모드 전환·단계 제목·숫자 카드는 사용하지 않습니다. 기존 앱에서 **백업 저장**으로 파일 앱에 JSON을 저장하고, 새 앱에서 **백업 불러오기**로 선택합니다. 파일을 선택한 뒤에만 날짜·포함 기록을 왼쪽 정렬한 복원 내용을 표시하며 개별 화학동 시각은 펼쳐 확인합니다. **이 기록으로 복원**을 누르고 PM 관리에서 기록을 확인한 뒤 기존 앱을 정리합니다. 취소하면 기본 목록으로 돌아갑니다. 기존 앱에 메뉴가 없으면 앱을 완전히 닫고 다시 열어 최신 화면을 불러오세요.

백업은 화학동 6개 라인, 액퍼내기 4개 라인, 특이사항·PM 요일 변경·확정일, 기존 진행 기록을 포함합니다. 원문 대화나 브라우저의 다른 데이터는 담지 않습니다. 서버 전송 없이 파일을 직접 저장·선택하며, 네이티브 공유를 지원하면 공유 시트의 파일 저장을 사용하고 그 외에는 다운로드합니다. 저장 안내는 실제 파일 저장을 보장하지 않으므로 파일 앱에서 확인합니다.

파일을 선택하는 것만으로는 기록을 바꾸지 않습니다. 형식·필수 필드·시각·SHA-256을 검사한 뒤 미리보기를 표시하고 명시적으로 복원할 때 전체 상태를 바꿉니다. 복원 직전 상태는 `pm_before_transfer_master`에 먼저 보관하며 **복원 전 기록 확인**에서 미리보기 후 되돌릴 수 있습니다. 연결된 기기에서 복원하면 복원된 기록은 동기화됩니다. 저장 실패 시 현재 상태를 유지합니다.
