# 동도금 PM 모니터링

실제 웹 진입 파일은 `index.html`입니다. 기존 `pm_schedule.html` 요구사항과 이후 Work/Codex 수정 기록을 통합합니다. 개인용으로 사용 중인 브라우저에만 저장합니다. 기존 기기 기록과 영구 저장 키는 보존합니다.

## 사용 흐름

- **PM 관리**: 오늘/내일 또는 선택한 날짜의 일정과 공정별 카드 확인 → 공지 복사. 화학동 시작·완료·시간정정은 같은 첫 화면에서 처리합니다. 공지 입력 및 특이사항 추가 바로가기를 제공합니다.
- 화학동 상태 요약을 누르면 첫 화면의 화7·8·9·13·14 카드로 이동합니다. 진행 중 경과 시간·12시간 액이송·14시간 PM 목표, 직전 완료와 차기 예정 시각을 표시합니다. 수동 분 입력은 00/30분이며 기존 저장값·메시지의 분 정밀도는 유지합니다.
- **특이사항**: 약품 건욕·기본 PM을 제외한 별도 공사·점검·교체·일정만 문장 해석 또는 날짜·라인·내용 직접 입력으로 저장합니다. 저장된 날짜의 공지에 `(특이사항)`으로 자동 추가하며, 새로고침 후에도 유지합니다. 수정·삭제와 해당 날짜 공지 보기를 제공합니다. 유산동 필터 교체·옥사멧 점검·인써트 교체·설비공사·설비점검 태그를 제공합니다. 건욕·기본 PM 입력과 혼합 문장은 저장하지 않고 안내합니다.
- 주간 매트릭스와 액퍼내기는 헤더의 별도 창으로 엽니다.

## 적용 순서와 유지하는 후속 변경

Gemini 정리 이후의 수정은 아래와 같이 우선 반영합니다.

- 전12도 산탈지.산세.박리를 기본 PM으로 사용합니다. 전9·14·20·21도 같은 기본 명칭입니다.
- 진행 중 공지 문구는 `-화13 10시 PM 진행중` 형태입니다. 작업명·분은 데이터와 현황 카드에 보존합니다.
- 전기동은 항상 7시패스로 고정합니다. 붙여넣은 공지와 이전 저장값의 다른 패스 시각은 적용하지 않습니다. 브리핑·복사 원문·게이지가 같은 기준을 사용합니다.
- 디스미어 13/14는 수동 기준일 이후 실제 화학동 완료 2회마다 1회 안내합니다. 기준일을 등록하지 않으면 자동으로 과거 회차를 추정하지 않습니다.
- 디스미어 공지는 화학동 상태를 바꾸지 않습니다. 수동 등록으로 기준일을 관리합니다.
- 화면은 재구성 이전 main(436fe21)의 배치와 파란색 테마로 복원합니다. 브리핑 상단의 인라인 카톡 입력, 브리핑 아래의 고정 순서 화학동 카드, 첫 화면 화학동 카드의 시작·완료·시간정정 기능을 유지합니다. 진척·화학동 전용 탭을 제거하고 PM 관리·특이사항 2개 탭을 제공합니다. 상태 요약은 첫 화면 화학동 카드로 이동합니다. 기존 진척 데이터는 지우지 않습니다.
- Google 로그인·서버 저장·연결 및 데이터 관리 메뉴를 사용하지 않습니다. 기록은 현재 브라우저에 자동 저장합니다.
- 카톡 붙여넣기와 백라이트/완료 인식, 기기 데이터 복구 개선은 유지합니다. 이후 UI 개편의 대시보드·필터·공지 팝업·접힌 화학동 상세 화면은 제거합니다.

## 공정 기준

- 에칭: 일요일을 포함한 에1.2 → 에3.4 → 에6 3일 순환. 2026-09-25는 에3.4 기준입니다.
- 화학동: 실제 완료 후 72시간. 화8 완료 후 48시간 초과 시 빌드업 금지.
- 화학동 진행: 12시간 액이송, 14시간 미완료 지연. 다음 PM까지 7시간 이내면 임박 표시.
- 일반 전기동: 08:30 기준 12시간 후인 20:30부터 미완료 지연. 더미 1.5시간.
- 펄스: 0.5 DC → 1.5 DC → 펄스패스 → 펄스더미, 단계별 1.5시간.
- 일일 브리핑의 화학동 포함 범위는 당일 08:30 이상부터 익일 08:30 미만입니다.
- 격주 기준과 전체 매트릭스는 기존 일정을 유지합니다.

## 공지와 저장 처리

- 날짜 없는 진행/완료 공지의 시간이 현재보다 미래면 전날로 해석합니다. 날짜가 명시된 미래 기록은 완료로 반영하지 않습니다.
- 오래된 시작·완료 공지는 최신 기록과 작업명을 덮어쓰지 않습니다. 정정은 시간정정을 사용합니다.
- 백라이트 보고에서 PM인 라인만 진행 근거로 보관합니다. 이후 날짜·시각이 있는 양산/액수위 신호가 나오면 완료 후 72시간을 계산합니다. 일반 측정값, 미완료·취소·예정 표현은 완료로 만들지 않습니다.
- 완료 메시지 날짜·시각이 없으면 확인 입력을 요구하고 공지 원문을 유지합니다.
- 버전이 다른 저장 키는 동적으로 검색하되 마스터를 우선합니다. 손상된 항목은 유효한 이전 버전에서 복구합니다.
- 실제 기록이 없는 화학동 라인은 기본 날짜로 임의의 진행/지연을 표시하지 않습니다. 5개 라인은 항상 보이며 시간정정으로 실제 기록을 입력합니다.
- `pm_local_state_master`에 전체 상태를 한 번에 저장합니다. 기존 마스터 키도 호환 사본으로 유지하며, 이전 저장 대기열은 기기 안에서 한 번 복구한 뒤 정리합니다. 외부로 전송하지 않습니다.
- 수집 메시지 완료도 수동 완료와 같은 회차 식별자로 집계해 디스미어 계산의 중복을 막습니다.

## 개인용 저장

기록은 현재 사이트를 사용하는 이 브라우저에만 저장됩니다. 기기·브라우저·사이트 주소가 달라지면 기록을 공유하지 않습니다. 서버 연결, 로그인, 동기화, 재시도, 자동 수집 JSON 관리, 백업 관리 UI와 업로드 CLI는 제거했습니다. CSP의 `connect-src 'none'`으로 앱에서 외부 데이터 연결도 차단합니다.

브라우저의 사이트 데이터를 지우면 저장 기록도 삭제됩니다. 기존에 이 기기에 저장된 PM·특이사항·타이머 기록은 그대로 복구합니다. 이 변경은 외부 계정이나 저장소의 데이터를 삭제하지 않습니다.

## 검증

Node.js 18 이상에서 외부 서비스 없이 실행합니다.

```sh
node --test tests/pm-regression.cjs tests/kakao-automation.cjs
```

실행 검사는 분리한 DOM/브라우저 저장소 환경을 사용합니다. 실제 서버 연결 없이 원본 페이지로 화면을 검증합니다. 실제 iPhone Safari 확대·키보드 동작은 별도 실기기 검증 대상입니다.

## 날짜별 특이사항 기억

특이사항 탭에 `디스미어12 옥사멧점검 이번주 수요일에 진행예정 이오니 준비 바랍니다.`를 붙여넣고 **문장에서 일정 가져오기**를 누릅니다. 2026-10-27 기준 `2026-10-28 / 디스미어 12 / 옥사멧 점검`을 확인하고 **저장**하면 10월 28일 공유 원문에 `디12 기본PM (옥사멧 점검)`이 포함됩니다. 해석만으로는 저장하지 않습니다. 예시 일정은 기본 데이터에 미리 저장하지 않습니다.

- 오늘·내일·모레, 이번/다음 주 요일, 연월일·월일·일자를 해석합니다. 주는 월요일부터 계산합니다. 연도 없는 월일/일자는 다가오는 날짜, 이번 주 요일은 해당 주의 날짜로 해석하므로 저장 전 확인합니다. 반복 일정·여러 날짜·여러 라인은 나누어 입력합니다.
- 날짜와 라인, 공유 문구는 저장 전에 직접 수정할 수 있습니다. 전체 날짜를 보관하므로 월말·연말에도 같은 일자에 혼입되지 않습니다.
- 추가 특이사항은 기존 기본PM/전기동 작업과 7시패스를 유지하면서 괄호로 덧붙입니다. 정기 PM이 없는 날은 `디12 (옥사멧 점검)`처럼 작업만 공유하며 기본PM이나 전기동 건욕을 새로 만들지 않습니다. 화학동 시작/완료나 인라인 디스미어 기준 회차를 바꾸지 않습니다.
- 기기 전체 상태와 기존 `manual_notes_master`에 저장합니다. 대화 원문 대신 확인한 날짜·라인·공유 문구만 저장합니다.

## 필요한 작업만 표시

- 특이사항의 빈 상세 입력과 빈 목록은 숨깁니다. 문장을 입력하면 해석 버튼, 해석 성공 시 확인·저장 입력을 표시합니다. 직접 입력·기존 기록 수정은 해당 입력을 바로 엽니다. 원문을 바꾸면 이전 해석 화면을 숨겨 다시 확인하도록 합니다.
- 저장 후 입력을 접고 일정 목록을 표시합니다. 오늘·예정 작업을 먼저, 지난 기록은 접힌 목록으로 보관합니다. 선택한 브리핑 날짜의 과거 기록은 펼쳐 표시합니다. 표시 여부를 바꿀 때 저장 데이터는 삭제하지 않습니다.
- 디스미어 13/14 보조 카드는 해당 브리핑 시간대에 PM 일정 또는 해당 날짜 메모가 있는 라인만 표시합니다. 등록 가능한 라인과 기존 회차 계산은 유지합니다.
- 저장된 일정의 **이 날짜 공지 복사**는 그 날짜로 이동하여 PM 전체 공지를 한 번에 복사합니다.

## 특이사항과 약품 PM 구분

특이사항은 유산동 필터 교체·옥사멧 점검·인써트 교체 같은 별도 공사·점검·교체 일정입니다. 약품 건욕·기본/정기 PM·산탈지/산세/박리 등은 특이사항으로 저장하지 않습니다. 약품 배관 공사·건욕 탱크 보수·산세 펌프 교체 같은 설비 공사는 허용합니다. 해석과 직접 저장에 같은 검사를 적용합니다. 두 내용을 섞은 문장은 PM 내용을 빼고 다시 입력하도록 안내합니다.

기존 PM 데이터는 삭제하지 않으며 특이사항 목록에서 제외합니다. 디스미어 13/14의 실제 PM 기준일은 첫 화면 **디스미어 13·14 PM 기록**에서 입력·관리합니다. 별도 작업은 PM 기준일이나 자동 완료 회차를 바꾸지 않으며 수동 처리와 자동 수집도 같은 구분을 적용합니다. 카톡 공지의 건욕 작업과 별도 작업은 각각 분리해서 반영합니다.
